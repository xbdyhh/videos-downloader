# Third-party software

This project bundles the following unmodified runtime distributions:

- `mux.js` 6.3.0 — Apache-2.0 — https://github.com/videojs/mux.js
- `@ffmpeg/ffmpeg` 0.12.15 — MIT — https://github.com/ffmpegwasm/ffmpeg.wasm
- `@ffmpeg/core` 0.12.10 — GPL-2.0-or-later — https://github.com/ffmpegwasm/ffmpeg.wasm

The corresponding package versions are pinned in `package.json` and `package-lock.json`. Before redistributing the extension, review and comply with these licenses, including the source-code obligations that apply to the bundled FFmpeg core.
